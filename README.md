# Tainacan

Projeto pessoal para agregar conteúdo de diversos sites que estão usando a ferramenta Tainacan, disponível para WordPress.
[https://tainacan.vercel.app](https://tainacan.vercel.app).

## Desenvolvimento

Package manager: **Bun**. O CLI do Next.js (`dev` / `build` / `start`) roda sob o Bun via `bun --bun`.

```bash
bun install
bun run dev
bun run build
bun run start
bun run typecheck
bun run lint
```

## Front-end:

- TypeScript
- React
- Next.js
- Next-SEO
- Next-Themes
- Tailwind CSS
- shadcn/ui
- Lucide Icons
- Axios
- TanStack Query (React Query)

## Back-end:

- Todas as instâncias do Tainacan que eu encontrei e que respondiam em um tempo aceitável
